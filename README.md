# Portofolio Arif Tripurna Putra

Website portofolio statis satu halaman.

## Isi
- `index.html` — website utama.
- Foto profil sudah tertanam di dalam `index.html`, jadi tidak perlu file foto terpisah.

## Deploy ke Vercel
1. Ekstrak ZIP ini.
2. Buat repository baru di GitHub.
3. Unggah `index.html` dan `README.md` ke root repository.
4. Di Vercel, pilih **Add New → Project** lalu impor repository GitHub.
5. Pilih Framework Preset **Other**.
6. Biarkan Build Command dan Output Directory kosong.
7. Klik **Deploy**.

Vercel akan memberikan URL website setelah proses deploy selesai.
